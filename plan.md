**AWB Receipt Management System – Scope of Work (₹15,000)**

The following features will be included:

1. **User Authentication**
    - Secure login and logout.
    - Admin and Regular User roles.

2. **User Management**
    - Admin can create, view, edit, and deactivate users.
    - Role-based access and permissions.

3. **AWB Receipt Creation**
    - Create AWB receipts with sender and receiver details.
    - Add multiple item descriptions and quantities manually.
    - Automatic unique AWB number generation.

4. **Barcode Generation**
    - Automatically generate a barcode for each AWB receipt.
    - Display the barcode on the receipt for scanning.

5. **Receipt Management**
    - View receipt details.
    - Maintain receipt history.
    - Search receipts by AWB number, sender name, or receiver name.
    - Filter receipts by date.

6. **Receipt Printing**
    - Professional, printer-friendly receipt format.
    - Print receipts with AWB number, barcode, sender, receiver, and item details.

7. **Dashboard**
    - Basic dashboard with receipt statistics and recent receipts.

8. **Responsive UI**
    - Clean and user-friendly interface.
    - Responsive design for desktop, tablet, and mobile.

9. **Security and Access Control**
    - Secure password handling.
    - Role-based permissions.
    - Users can access only the receipts permitted by their role.

10. **Deployment**
    - Application deployment on Cloudflare.
    - Database setup using Cloudflare D1.
    - Basic production configuration.

11. **Testing and Documentation**
    - Basic functional testing.
    - Setup and deployment documentation.

**Technology Stack:** Next.js, TypeScript, Tailwind CSS, shadcn/ui, Cloudflare Workers, Cloudflare D1, and Drizzle ORM.

**Note:** Product inventory management, product catalogue, shipping carrier integration, payment integration, paid third-party services, and ongoing maintenance are not included in this scope unless agreed separately.
